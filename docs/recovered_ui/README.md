# Recovered UI reference pack

**Status:** Design reference material for R3C visual-direction audit.  
**Not** factual/product-state SSOT.

## What this pack is

- Static HTML + `renders.css` recovered as the closest surviving candidate expression of the intended Northstar UI.
- Useful for hierarchy, typography, surfaces, density, and component composition comparison against the live product.

## What this pack is not

- Not runtime truth. Names, counts, times, flights, case facts, costs, and statuses inside these HTML files are **illustrative examples only**.
- Authoritative facts remain in application read models plus:
  - `docs/FINAL_DEMO_CONTENT_SSOT.md`
  - `docs/SCENARIOS.md`
  - `docs/DESIGN.md` (general visual language)

## Assets

- Original PNG screenshot/hero assets from the prior design pass are **gone**.
- `assets/sg-dusk.png` is an **AI-generated replacement**, not recovered original material. Do not describe it as original.

## Do not treat as design authority

- `data/ui-preview/**`
- `output/r3b-visual/ref-*.png`
- later generated fixture previews
- claims that visual parity was already achieved

Those are downstream proxies. This pack is the design-reference baseline for R3C.
