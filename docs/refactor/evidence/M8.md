## M8 implementation summary

### Authority

- Envelope fingerprint binds plan/intent/version/scope/limits (`envelope.ts`)
- Typed grants + multi-actor approvals + revocation (`authorize.ts`, migrations 0102)
- Organisation/Traveller are not authenticated principals
- No case-wide reusable approval — fingerprint mismatch denies dispatch
- Grant expiry / revocation / amount ceiling enforced at decision time

### Budget

- `admitBudgetHold` + `holdBudgetForIntent` with FOR UPDATE concurrency
- Prevents overspend, duplicate commitment, currency mismatch, quote > approved ceiling
- Exact money seam shared with Checkpoint 0 / I-10

### Durable execution

- Migrations 0100–0105: recovery_cases (minimal M7 seam), action plans/intents,
  authority decisions/approvals, execution attempts/observations, budget commitment FK,
  action kinds
- State machine: PREPARED → CLAIMED → DISPATCHING → … → OBSERVED_* / OUTCOME_UNKNOWN /
  RECONCILIATION_REQUIRED / COMPLETED / FAILED
- `PgExecutionWorker`: claim fencing, capability gate, lost-response → UNKNOWN → reconcile
- Lease expiry never authorises blind irreversible retry
- Same logical key + same fingerprint: safe replay; different fingerprint: reject

### Capability separation

- Observe ≠ service; unsupported capability → structured FAILED without fake success

### Internal ProgrammeItem

- `executeInternalProgrammeItemSchedule`: authority → durable claim path → M4 schedule
  command → internal observation → intent COMPLETED

### Shared-contract notes (integration owner)

- Minimal `recovery_cases` parent table (0100) — shared M7/M8 seam
- `ExecutionAttemptStatusSchema` extended with CLAIMED / DISPATCHING /
  RECONCILIATION_REQUIRED / COMPLETED / FAILED
